# Follow-up note template

Send within 24 hours of the meeting. If owners or dates are missing, list the gaps at the top so the sender resolves them before sending, never after.

```
[Meeting name] follow-up, [date]

[If any: GAPS TO RESOLVE BEFORE SENDING: action 2 needs an owner, action 4 needs a date]

Decisions:
- We will [decision, stated as a commitment, not a topic]
- We will [decision]

Summary:
[Three sentences maximum. What was worked, what changed, what remains open.]

Action items:
- [Action]. Owner: [name]. Due: [date].
- [Action]. Owner: [name]. Due: [date].

Learnings:
- [Anything learned that changes how the team works going forward]
```

## Filled example

```
Strategic Review follow-up, Aug 12

Decisions:
- We will ship the lifecycle plan on Sep 8 with the reduced segment scope.
- We will hold the win-back track until the deliverability review closes.

Summary:
The plan was approved with one scope cut. The win-back track is paused pending
the deliverability review. Budget and staffing stand as proposed.

Action items:
- Trim the segment matrix to the approved scope. Owner: Cindy. Due: Aug 15.
- Book the deliverability review. Owner: Andrew. Due: Aug 14.
- Update the launch calendar and notify ops. Owner: Katy. Due: Aug 13.

Learnings:
- Exceptions-only walkthroughs cut review time in half; adopt for future plan reviews.
```
