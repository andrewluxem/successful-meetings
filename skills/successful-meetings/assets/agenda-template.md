# Agenda template

Fill every field. If the Objective line cannot be written, the meeting is not ready to schedule; draft the replacement email or doc instead.

```
Agenda: [Meeting name]
Objective: [One sentence: the decision or outcome this meeting exists to produce]
Owner: [Name]
Type: [Process-oriented | Mission-oriented]
Date and time: [Date, start to end, timezone]
Attendees:
  - [Name] (Owner)
  - [Name] (Decider)
  - [Name] (Contributor: what input they bring)
Informed, gets the notes: [Names]
Materials, shared in advance: [Docs, decks, dashboards]
Send agenda and materials by: [At least 24 hours before start]

Items:
1. [Item] ([N] min) [What done looks like for this item]
2. [Item] ([N] min) [What done looks like for this item]
Final 5 min: decisions, owners, dates

Discussion questions:
- [3 to 5 questions matched to the meeting's job]
```

## Filled example

```
Agenda: Strategic Review, Lifecycle Plan
Objective: Approve the lifecycle plan for Q4 or return it with owned revisions.
Owner: Andrew
Type: Mission-oriented
Date and time: Aug 12, 10:00 to 10:30 MT
Attendees:
  - Andrew (Owner)
  - Katy (Decider)
  - Cindy (Contributor: channel capacity and calendar constraints)
Informed, gets the notes: Ops team
Materials, shared in advance: Plan doc, summary deck
Send agenda and materials by: Aug 11, 10:00 MT

Items:
1. Plan walkthrough, exceptions only (10 min) Open questions surfaced, not resolved
2. Risks and tradeoffs (10 min) Each risk has a named owner or an accepted label
3. Decision (5 min) Approve, or return with specific revisions
Final 5 min: decisions, owners, dates

Discussion questions:
- What is the worst case if we ship this as written?
- Why now, instead of next quarter?
- How will we measure success by week 4?
```
